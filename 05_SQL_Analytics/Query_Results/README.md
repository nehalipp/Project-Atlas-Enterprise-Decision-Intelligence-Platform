# Query Results

This folder contains sample outputs generated by executing the SQL queries against the Project Atlas Enterprise Data Warehouse.

The CSV files demonstrate the analytical results that can be visualized in reporting tools such as Power BI and Tableau.

## Available Results

- Executive KPIs
- Monthly Revenue Trend
- Revenue by Country
- Revenue by Sales Channel
- Top Customers
- Top Products
- Total Revenue

These files are intended for demonstration purposes only.
