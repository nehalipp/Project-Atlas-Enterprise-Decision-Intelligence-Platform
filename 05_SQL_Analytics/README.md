# SQL Analytics

## Overview

This folder contains business-focused SQL analyses built on the Project Atlas Enterprise Data Warehouse.

The queries are designed to answer common business questions using the dimensional star schema.

---

## Topics Covered

- Sales Performance
- Customer Analytics
- Product Analytics
- Location Analytics
- Supplier Analytics
- Executive KPIs

---

## Skills Demonstrated

- SQL Joins
- Aggregations
- GROUP BY
- ORDER BY
- Window Functions
- Common Table Expressions (CTEs)
- Business KPI Calculations
- Star Schema Navigation
