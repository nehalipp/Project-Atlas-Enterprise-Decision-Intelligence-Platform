# Project Atlas: Enterprise Decision Intelligence Platform

## Overview

Project Atlas is an enterprise analytics platform designed to integrate, transform, analyze, and visualize data across multiple business domains.

The platform demonstrates modern analytics engineering practices including:

- Data Engineering
- Data Warehousing
- Data Quality Management
- Business Intelligence
- Analytics Automation

## Business Domains

- Sales Analytics
- Finance Analytics
- Supply Chain Analytics
- Operations Analytics
- Customer Analytics
- Workforce Analytics
- ESG Analytics

## Technology Stack

- PostgreSQL
- Python
- SQL
- Power BI
- Tableau
- dbt
- Azure
- Git
